# Zappfy

LucroTrack - Sistema de Gestão Financeira para Vendas pelo WhatsApp

Crie uma aplicação SaaS moderna chamada LucroTrack.

O objetivo da plataforma é ajudar lojas locais que vendem pelo WhatsApp a organizar pedidos, controlar vendas, acompanhar faturamento, registrar despesas e visualizar o lucro real da operação automaticamente.

A aplicação deve ser moderna, rápida, intuitiva e extremamente fácil de usar, mesmo para pessoas sem conhecimento em gestão financeira.
